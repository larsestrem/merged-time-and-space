🚩 Reports

Abuse reports, wrong-date corrections and event suggestions submitted through the site's forms.

Where reports live: each submission is stored in Cloudflare KV for 90 days and, if email is configured, sent to you. For this page to work, in Cloudflare Pages → Settings → Functions set MOD_LOG_KEY (a long secret) and bind a KV namespace named RATE. For email delivery, also set RESEND_API_KEY, FROM_EMAIL and (optionally) REPORT_EMAIL. This page is noindex and data is only returned with the correct key.
